### 1.3 Chatbot Component Integration

Add chatbot widget to layout (`src/components/ChatBot.jsx`):
```jsx
import React, { useState } from 'react';

export default function ChatBot() {
  const [isOpen, setIsOpen] = useState(false);
  const [query, setQuery] = useState('');
  const [answer, setAnswer] = useState('');
  const [loading, setLoading] = useState(false);
  const [sessionId] = useState(() =>
    localStorage.getItem('session_id') || crypto.randomUUID()
  );

  const handleSubmit = async (e) => {
    e.preventDefault();
    setLoading(true);
    try {
      const response = await fetch(
        `${process.env.REACT_APP_API_URL}/api/chat`,
        {
          method: 'POST',
          headers: { 'Content-Type': 'application/json' },
          body: JSON.stringify({ query, session_id: sessionId })
        }
      );
      const data = await response.json();
      setAnswer(data.answer);
    } catch (error) {
      setAnswer('Chat service temporarily unavailable.');
    } finally {
      setLoading(false);
    }
  };

  // Render chatbot panel with query input and answer display
  // (Full implementation in task phase)

  return (
    <div className="chatbot" style={{ display: isOpen ? 'block' : 'none' }}>
      <form onSubmit={handleSubmit}>
        <input
          value={query}
          onChange={(e) => setQuery(e.target.value)}
          placeholder="Ask about the textbook..."
        />
        <button type="submit" disabled={loading}>
          {loading ? 'Processing...' : 'Send'}
        </button>
      </form>
      {answer && <div className="answer">{answer}</div>}
    </div>
  );
}
```

**`src/api/routes.py`**:
```python
from fastapi import APIRouter
from api.models import ChatRequest, ChatResponse
from rag.retrieval import retrieve_and_answer
import time

router = APIRouter()

@router.post("/api/chat")
async def chat(request: ChatRequest) -> ChatResponse:
    start = time.time()
    status, answer, sources = retrieve_and_answer(request.query)
    latency_ms = int((time.time() - start) * 1000)
    return ChatResponse(
        status=status,
        answer=answer,
        sources=sources,
        latency_ms=latency_ms
    )

@router.get("/api/health")
async def health():
    return { "status": "healthy", "timestamp": "..." }
```

### 3.2 Embed & Index to Qdrant

**Script**: `indexing/load_to_qdrant.py`

```python
from sentence_transformers import SentenceTransformer
from qdrant_client import QdrantClient
from qdrant_client.models import PointStruct

# Load or start Qdrant (local Docker or cloud)
client = QdrantClient(url="http://localhost:6333")  # local Docker
# or
# client = QdrantClient(url="https://qdrant.io", api_key="...")  # cloud

# Load chapters
with open("chapters.json") as f:
    chunks = json.load(f)["chunks"]

# Embed
model = SentenceTransformer('all-MiniLM-L6-v2')
embeddings = model.encode([chunk["text"] for chunk in chunks])

# Index to Qdrant
points = [
    PointStruct(
        id=i,
        vector=emb,
        payload={"chapter": chunk["chapter"], "section": chunk["section_id"], "text": chunk["text"]}
    )
    for i, (emb, chunk) in enumerate(zip(embeddings, chunks))
]
client.upsert(collection_name="textbook_chunks", points=points)
```

## 5. Chapter Authoring Guide

### Writing Your Chapter

**File**: `docs/01-introduction-to-physical-ai/embodied-intelligence.md`

```markdown
---
id: embodied-intelligence
title: Embodied Intelligence
sidebar_position: 1
---

# Embodied Intelligence

## Definition

Embodied intelligence refers to the idea that intelligence emerges from the interaction of an agent with its environment through physical embodiment.

### Why It Matters

Physical agents must perceive and act in real-world environments, which introduces constraints and opportunities absent from purely symbolic systems.

## Key Concepts

- **Perception**: How robots sense their environment
- **Action**: How robots affect their environment

## Further Reading

- Related concept: Digital Twin Simulation (Chapter 4)
- See also: Vision-Language-Action Systems (Chapter 5)
```

### Markdown Best Practices

- Use **clear headings** (H2/H3 for sections)
- Include **code blocks** with syntax highlighting:
  ```python
  class PhysicalAgent:
      def perceive(self): pass
      def act(self): pass
  ```
- Add **links to other chapters**: `[Chapter 4: Digital Twin](../04-digital-twin-simulation/index.md)`
- Include **images**: `![Robot diagram](./images/robot.png)`
- Use **blockquotes** for definitions or notes:
  > **Definition**: Embodied intelligence is...

## Troubleshooting

| Issue | Solution |
|-------|----------|
| Docusaurus build fails | Check Markdown syntax; run `npm run build` for detailed errors |
| FastAPI startup error | Verify Python 3.11+, Sentence Transformers installed |
| Qdrant connection error | Ensure Qdrant running: `docker run -p 6333:6333 qdrant/qdrant` |
| CORS errors in frontend | Check backend CORS config matches frontend URL |
| Slow page loads | Check Docusaurus bundle size; optimize images |
| RAG accuracy low | Increase chunk size (up to 1000 tokens); test more queries |
