HOW TO USE
================================================================================

START EVERYTHING:

Terminal 1 - Backend:
  $ cd backend
  $ uvicorn src.main:app --reload --host 0.0.0.0 --port 8000

Terminal 2 - Frontend:
  $ cd mybook
  $ npm run dev

OPEN IN BROWSER:
  http://localhost:3000

CLICK CHATBOT:
  Look for purple button (💬) in bottom-right corner
  Click to open chat panel

SEND MESSAGE:
  Type: "What is ROS2?"
  Press Enter or click Send button
  View response with sources and relevance scores
