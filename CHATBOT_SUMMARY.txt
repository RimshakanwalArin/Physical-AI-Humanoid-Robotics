⚙️ ONE-TIME SETUP (Before First Use)
================================================================================

1. CREATE CONFIGURATION:
   cp .env.example .env

2. ADD YOUR CREDENTIALS TO .env:
   DATABASE_URL=...      (from Neon: https://neon.tech)
   ANTHROPIC_API_KEY=... (from Claude: https://console.anthropic.com)

3. INITIALIZE DATABASE:
   cd backend
   python scripts/init_neon_db.py

4. INDEX YOUR DOCUMENTS:
   python scripts/index_documents.py --docs ../mybook/docs

5. DONE! Now run START_CHATBOT.bat (Windows) or start_chatbot.sh (Mac/Linux)

================================================================================
🐛 TROUBLESHOOTING
================================================================================

PROBLEM: "Cannot connect to localhost:3000"
SOLUTION: Make sure frontend server is running (green text in terminal)

PROBLEM: "Chatbot gives error"
SOLUTION: Check backend is running on port 8000

PROBLEM: "No responses to questions"
SOLUTION:
  1. Check DATABASE_URL is correct
  2. Check ANTHROPIC_API_KEY is set
  3. Run indexing: python backend/scripts/index_documents.py --docs ../mybook/docs
  4. Lower MIN_SIMILARITY to 0.4 in .env

PROBLEM: "pgvector not found"
SOLUTION: Run python backend/scripts/init_neon_db.py

PROBLEM: "Import errors"
SOLUTION: pip install -r backend/requirements.txt
